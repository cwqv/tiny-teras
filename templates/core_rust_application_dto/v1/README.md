# Core Rust DTO Template v1

## 描述
用于生成 Rust 后端 DTO（Data Transfer Object）的模板集合。

## 模板文件
- `dto_file_header.tera` - 文件头部（导入语句）
- `dto_create.tera` - Create DTO 模板
- `dto_created.tera` - Created DTO 模板（响应）
- `dto_get.tera` - Get DTO 模板
- `dto_list.tera` - List DTO 模板
- `dto_update.tera` - Update DTO 模板
- `dto_delete.tera` - Delete DTO 模板

## 版本控制
- 当前版本：v1
- 如需修改模板，建议创建新版本（如 v2）以保持向后兼容
